Lanzamiento inicial de `@mific/ui` (v0.1.0):
- 19 componentes de interfaz institucional accesibles basados en Radix UI.

- Soporte multi-entorno para aplicaciones con React 18 / React 19 y Tailwind CSS v3, v4 o sin Tailwind.
- Documentación interactiva y catálogo de componentes en Storybook 8.6.

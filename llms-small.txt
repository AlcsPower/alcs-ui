# @alcspower/ui — Concise Agent Reference

Accessible React 18/19 component library (59+ components) with semantic Tailwind CSS v4 tokens, Radix UI primitives, CVA, and bundled sub-dependencies (zero external runtime dependencies beyond react + react-dom).

## Critical Rules
1. ALWAYS import from '@alcspower/ui': `import { Button, Card, ... } from '@alcspower/ui'`
2. ALWAYS import CSS once: `import '@alcspower/ui/styles.css'` (or `@import "@alcspower/ui/styles.css"` in CSS)
3. ONLY use semantic tokens (`bg-alcspower-primary`, `text-alcspower-foreground`, `border-alcspower-border`). NEVER hardcode hex colors or static Tailwind colors (e.g. `bg-blue-600`).
4. Merging classes: ALWAYS use `cn()` from '@alcspower/ui'.
5. Toasts: Place `<Toaster position="bottom-right" richColors />` in app root; trigger with `toast.success()`, `toast.error()`, etc.
6. Polymorphism: Use `asChild` prop (Radix Slot) to render components as links or custom tags.

## Design Tokens (--alcspower-*)
- Backgrounds: `bg-alcspower-background`, `bg-alcspower-surface`, `bg-alcspower-surface-muted`, `bg-alcspower-primary`
- Foreground: `text-alcspower-foreground`, `text-alcspower-muted-foreground`, `text-alcspower-primary`
- Borders: `border-alcspower-border`, `border-alcspower-border-strong`
- States: `bg-alcspower-destructive`, `bg-alcspower-success`, `bg-alcspower-warning`, `bg-alcspower-info`
- Dark mode: activated via `.dark` class or `[data-theme="dark"]` attribute.
